## Vulnerabilidades Identificadas

### 🔴 ALTA SEVERIDAD

#### 1. Falta de Verificación de Capabilities en Función de Renderizado del Admin

**Archivo:** `noindex-seo.php`
**Línea:** 454
**Función:** `noindex_seo_admin()`
**CWE:** CWE-862 (Missing Authorization)

**Descripción:**
La función que renderiza la página de administración no verifica explícitamente las capacidades del usuario. Aunque `add_options_page()` requiere la capacidad `manage_options` para acceder a la página, la función de callback debería verificar las capacidades como medida de defensa en profundidad.

**Código Vulnerable:**
```php
function noindex_seo_admin() {
    // NO HAY VERIFICACIÓN DE CAPABILITIES AQUÍ
    // Define sections and their respective settings.
    $sections = array(
        // ...
    );
```

**Impacto:**
Si hay un bypass en el control de acceso de WordPress o una configuración incorrecta, un usuario sin privilegios podría acceder a la interfaz de configuración.

**Recomendación:**
```php
function noindex_seo_admin() {
    // Verificar capabilities al inicio de la función
    if ( ! current_user_can( 'manage_options' ) ) {
        wp_die( esc_html__( 'You do not have sufficient permissions to access this page.', 'noindex-seo' ) );
    }

    // Define sections and their respective settings.
    $sections = array(
        // ...
    );
```

**Prioridad:** Alta
**Esfuerzo de Corrección:** Bajo (1-2 líneas de código)

### 🟡 MEDIA SEVERIDAD

#### 2. Falta de Sanitización de Input en Procesamiento de Formulario

**Archivo:** `noindex-seo.php`
**Líneas:** 418, 426
**Función:** `noindex_seo_process_form()`
**CWE:** CWE-20 (Improper Input Validation)

**Descripción:**
Aunque existe verificación de nonce y capabilities, los valores de `$_POST` no se sanitizan antes de verificar su existencia. Si bien el código solo verifica la presencia de las claves y siempre guarda valores hardcodeados (0 o 1), es una mala práctica de seguridad.

**Código Vulnerable:**
```php
// Línea 418
if ( isset( $_POST[ 'noindex_seo_' . $setting ] ) ) {
    update_option( 'noindex_seo_' . $setting, 1 );
}

// Línea 426
update_option(
    'noindex_seo_config_seoplugins',
    isset( $_POST['noindex_seo_config_seoplugins'] ) ? 1 : 0
);
```

**Impacto:**
Aunque el impacto real es bajo porque los valores guardados están hardcodeados, no seguir las mejores prácticas de sanitización puede llevar a vulnerabilidades futuras si el código se modifica.

**Recomendación:**
```php
// Línea 418
$post_value = isset( $_POST[ 'noindex_seo_' . $setting ] ) ? sanitize_text_field( wp_unslash( $_POST[ 'noindex_seo_' . $setting ] ) ) : '';
if ( ! empty( $post_value ) ) {
    update_option( 'noindex_seo_' . $setting, 1 );
}

// Línea 426
$config_value = isset( $_POST['noindex_seo_config_seoplugins'] )
    ? absint( $_POST['noindex_seo_config_seoplugins'] )
    : 0;
update_option( 'noindex_seo_config_seoplugins', $config_value );
```

**Prioridad:** Media
**Esfuerzo de Corrección:** Bajo (modificar 2 bloques de código)

#### 3. Falta de Validación de Nonce en Página de Admin

**Archivo:** `noindex-seo.php`
**Línea:** 454
**Función:** `noindex_seo_admin()`
**CWE:** CWE-352 (Cross-Site Request Forgery)

**Descripción:**
La función `noindex_seo_admin()` genera un formulario con un nonce (línea 651), pero no verifica el nonce al renderizar la página. Aunque la verificación real ocurre en `noindex_seo_process_form()`, es recomendable agregar verificación adicional si se procesan parámetros GET (como `?updated=true`).

**Código Actual:**
```php
function noindex_seo_admin() {
    // No verifica nonce ni parámetros GET
    // ...
    wp_nonce_field( 'update_noindex_seo_nonce' );
```

**Impacto:**
Aunque el parámetro `?updated=true` solo afecta la UI y no procesa datos, es una buena práctica validar todos los parámetros de entrada.

**Recomendación:**
Si en el futuro se agregan mensajes o procesamiento basado en parámetros GET:
```php
function noindex_seo_admin() {
    if ( ! current_user_can( 'manage_options' ) ) {
        wp_die( esc_html__( 'You do not have sufficient permissions to access this page.', 'noindex-seo' ) );
    }

    // Si se procesa el parámetro updated
    $show_updated = false;
    if ( isset( $_GET['updated'] ) && 'true' === $_GET['updated'] ) {
        // Verificar nonce si es necesario
        $show_updated = true;
    }
```

**Prioridad:** Media
**Esfuerzo de Corrección:** Bajo (solo si se agregan features que lean GET)

#### 4. Valores No Escapados en Atributos HTML

**Archivo:** `noindex-seo.php`
**Línea:** 686
**Función:** `noindex_seo_admin()`
**CWE:** CWE-79 (Cross-Site Scripting)

**Descripción:**
Aunque los valores provienen de un array interno controlado, las siguientes expresiones no están escapadas:

```php
echo esc_html( $field['recommended'] ) . ': <span class="dashicons ' . ( $field['suggestion'] ? 'dashicons-yes' : 'dashicons-no' ) . '" title="' . ( $field['suggestion'] ? 'Yes' : 'No' ) . '"></span>. ';
```

**Impacto:**
Bajo, ya que los valores provienen de un array interno. Sin embargo, si en el futuro se permite filtrar estos valores mediante hooks, podría convertirse en un vector XSS.

**Recomendación:**
```php
$dashicon_class = $field['suggestion'] ? 'dashicons-yes' : 'dashicons-no';
$dashicon_title = $field['suggestion'] ? 'Yes' : 'No';

echo esc_html( $field['recommended'] ) . ': <span class="dashicons ' . esc_attr( $dashicon_class ) . '" title="' . esc_attr( $dashicon_title ) . '"></span>. ';
```

**Prioridad:** Baja-Media
**Esfuerzo de Corrección:** Bajo

## Vectores de Ataque Potenciales

### 1. Cache Poisoning via Filter Hook
**Severidad:** Baja
**Vector:** Línea 78 - `apply_filters( 'noindex_seo_contexts', ... )`

Un plugin malicioso podría modificar los contextos mediante este filtro e inyectar claves de opciones arbitrarias. Sin embargo, el impacto es limitado porque:
- Solo afecta qué opciones se leen
- Las opciones deben existir previamente
- Los valores se convierten a booleano

**Mitigación Actual:** Validación de existencia de claves en array `$current_conditions`

---

### 2. Transient Timing Attack
**Severidad:** Muy Baja
**Vector:** Línea 107-118 - Cache de transients

Un atacante podría intentar invalidar el cache repetidamente, pero el impacto es solo de rendimiento, no de seguridad.

**Mitigación:** Límite de tiempo de 1 hora en el transient

## Recomendaciones de Seguridad Adicionales

### 1. Implementar Content Security Policy (CSP)
Agregar headers CSP en la página de admin para prevenir XSS:
```php
function noindex_seo_admin_csp() {
    if ( isset( $_GET['page'] ) && 'noindex_seo' === $_GET['page'] ) {
        header( "Content-Security-Policy: default-src 'self'; script-src 'self' 'unsafe-inline';" );
    }
}
add_action( 'admin_init', 'noindex_seo_admin_csp' );
```

### 2. Agregar Logging de Cambios de Configuración
Implementar logging cuando se modifican opciones críticas:
```php
function noindex_seo_log_changes( $old_value, $new_value ) {
    if ( $old_value !== $new_value ) {
        error_log( sprintf(
            'noindex SEO: User %d changed settings at %s',
            get_current_user_id(),
            current_time( 'mysql' )
        ) );
    }
}
add_action( 'update_option_noindex_seo_*', 'noindex_seo_log_changes', 10, 2 );
```

### 3. Implementar Rate Limiting
Agregar límite de intentos para prevenir ataques automatizados:
```php
function noindex_seo_rate_limit() {
    $transient_key = 'noindex_seo_rate_limit_' . get_current_user_id();
    $attempts = get_transient( $transient_key );

    if ( $attempts && $attempts > 10 ) {
        wp_die( 'Too many requests. Please try again later.' );
    }

    set_transient( $transient_key, ( $attempts ? $attempts + 1 : 1 ), MINUTE_IN_SECONDS );
}
```

### 4. Auditoría de Dependencias
Ejecutar regularmente herramientas de auditoría:
```bash
composer audit
composer outdated
```

### 5. Agregar Verificación de Integridad
Implementar checksums para archivos críticos:
```php
function noindex_seo_verify_integrity() {
    $expected_hash = 'sha256_hash_del_archivo';
    $actual_hash = hash_file( 'sha256', __FILE__ );

    if ( $expected_hash !== $actual_hash ) {
        // Alertar al administrador
        add_action( 'admin_notices', function() {
            echo '<div class="notice notice-error"><p>Security Warning: Plugin file integrity check failed!</p></div>';
        } );
    }
}
```
